## 回归自查

| 检查对象 | 结论 |
| --- | --- |
| F-01 与阶段修改计数 | 只有“已批准并落实”的修改才计次；拒绝或未落实提案不计次。Q-I 与 Q-II 的计数主体和归零条件未改变。 |
| F-01 与切换前 S 仲裁 | 修改批准负责授权写入，修改后 S 仲裁负责校验结果，切换前 S 仲裁负责最终阶段转换检查；三者触发时点和目的不同，不形成重复批准或循环等待。 |
| F-04 与零必需分支闸门 | 中间阶段只有在 output 配置和至少一个必需分支同时获批、一次性创建后才存在，不会以空阶段进入流水线。 |
| F-02 与状态写入频率 | 采用“步骤级进度按步骤边界写、其他字段按事件写”。普通步骤完成后写一次；有副作用或不可逆风险的步骤执行前后各写一次，没有细化到步骤内部每个变化。 |
| F-02 与不可逆恢复 | 状态为准备执行或结果未知的风险步骤禁止自动重跑，必须由用户确认实际效果。 |
| F-03 终态权限 | 阶段 output 的判定主体规则未改变；终态另有记录与判定主体，且生命周期“已完成”固定需用户授权。 |
| F-05 可选分支 | 可选分支失败仍受两轮上限防止无界循环，但达到上限后跳过，不误触必需路径的停机规则。 |
| F-06 指纹校验 | 指纹变更必须先有变更记录并完成治理复核，阶段切换不再无条件刷新指纹。 |
| F-07 四元体系 | 映射没有加入全序；通过成对记录复用 W/S 两个既有对象和场景，四元排序保持不变。 |
| F-08 状态真值 | Q-I、Q-II、失败与偏移明细表仍是唯一权威计数，摘要只用于快速恢复阅读。 |
| 前四轮其他成果 | 上位约束层、场景隔离、条件式仲裁、唯一人工介入清单、两道闸门和状态原子写入均未回退。 |
